# Pre-production script critique

Run this before voicing or filming. A script that passes the checker can still be dull. A script that breaks a convention can still be the best one. The job is to find what's weak and to protect what's unusual on purpose. (Finished-video review lives in slugshot-video-editing `references/review-and-approval.md`.)

## Read it twice

1. **As a stranger scrolling:** would you stop in the first seconds? Do you know what's going on? Do you care what happens? Did the ending pay off what the start promised?
2. **As the editor:** can each beat be shown? Is any line describing what the picture already shows?

## Questions (answer with specific lines, never a score)

| Area | Ask | Typical fix |
|---|---|---|
| Premise | Is it specific, original and picturable? Could anyone have written it, or only us? | Sharpen the rule; make it slug-native; swap in a stronger premise from the diverge list |
| Hook | Is the opening honest and striking, and different from our last videos? | Use one of the other written openings; lead with the consequence |
| Predictability | Where can the viewer see what's coming? | Subvert the third beat; cut to the reaction; move the reveal earlier |
| Progression | Does every beat change something? | Cut repeated beats; merge examples; add a cost |
| Exposition | Any line that explains instead of shows, or recaps? | Cut it or turn it into a character moment |
| Humour | Does it come from the situation? Is a joke explained, forced or a pasted meme? | Rebuild the setup; give the line to the right character; cut the explanation |
| Dialogue | Can you tell the speakers apart? Would they say this aloud? | Use the voice sheet; shorten; add an interruption |
| Payoff | Does it reframe or cash something planted earlier? | Plant the detail earlier; replace a hidden-power save with a callback |
| Slugshot fit | Which marketing job does it do? Would it work identically without our world? | Make the world or a slug the reason the story works |
| MUST | Any truth, IP, audience or reveal-lock problem? | Fix before anything else |

## Protect intentional choices

- If the writer marked a deliberate break (a slow deadpan read, no rule line, a 20-second sketch, an odd narrator), judge whether it *works*, not whether it's conventional. Don't correct it towards the average.
- Flag "this is unusual. Keep it, test it" as readily as "this is weak". Bold ideas that might fail are worth testing; safe ideas that can't stand out are not.

## Output

1. The 3 biggest problems, with line references and concrete fixes.
2. What's working and should be kept.
3. Deliberate choices you'd protect.
4. What needs the owner's ear (humour, voice, feel).

Then run the checker for text signals. Never present its output as a quality verdict.
