# TikTok genre research

We have permission to use Apify for the toolkit's TikTok collection. A person reads Creative Center.

Use the [command reference](../../docs/COMMANDS.md#tiktok-genre-research) for collection, subtitles, pooling and analysis. Dated Actor payloads are under `inputs/`. Run receipts and datasets stay under `data/local/research/creative/tiktok-genre/`, with permitted local video files under `media/research/tiktok-genre/`.

The November 2026 run built 631 in-format observations and TOP/MID/FLOP-50 transcript tiers. Its evidence is a dated sample, recorded in [Production quality](../../docs/production-quality.md) and the [pilot script archive](../../docs/archive/tiktok-genre/).
