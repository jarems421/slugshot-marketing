# Command reference

These are Claude's commands: give Claude Code a short instruction and it runs them (automation first, see CLAUDE.md). Run from the workspace folder: `.\ss <command>` (PowerShell) or `ss <command>` (cmd). Add `-h` to any command for every option. Paths can be relative to the workspace.

## Edit file keys (`assemble`)

Top level: `concept`, `hook_id`, `format` (preset), `language` ("en" default, "es": which accounts the edit is for; shown on its dashboard card), `dialogue` (an `ss dialogue` manifest: voice, captions and line anchors such as `"at": "L4.end+0.2"`; never tidied), `script` or `narration`, `voice` {`voice`, `speed`}, `tidy`, `sync` ("script"), `music`, `music_db`, `sfx` [{`src`, `at`, `db`}], `captions` ("auto" / path / null), `emphasis` [words], `hook`, `label`, `end_card`, `end_title`, `end_subtitle`, `accent`.

Scenes: `kind` (video/image/card), `src`, `text`, `seconds`, `trim_start`, `fit` (crop/blur/contain), `volume`, `zoom`, `punch_at` [s], `transition` (cut/fade), `label`, `captions` (true/false).

Examples: `jobs\bench\floppy-seven-qwenclone.json` (dialogue), `jobs\edit-sample-story.json`, `jobs\sample-variants.json`; dialogue script format: `jobs\dialogue\floppy-seven.txt`; script format: `jobs\scripts\sample-story.md`.
