# Dashboard: credential and account-authorisation checklist

Everything else is built and tested (publishing: fixture-tested). These steps need the owner (an account, a sign-in or an approval) and can't be done by Claude. Each one unlocks its part of the dashboard on its own; nothing here is needed for the rest to work. **All are free.** Where a value is a secret, paste it into **Settings → App credentials** (stored encrypted with Windows DPAPI in `data\local\dashboard\vault\`, git-ignored) or into `.env`. Never paste secrets into chat.

OAuth redirect URI to register wherever one is asked for: `http://127.0.0.1:47615/oauth/callback`

## Publishing permissions (uploads; [publishing.md](publishing.md))

Same apps, same vault and same redirect URI; uploads only add permissions. Everything is free. Nothing is posted until you approve a job in **Publish** by typing the account handle, and the reveal lock keeps everything private.

| # | Step | Where | Notes |
